원터치 하이퍼캐주얼 게임. 좌우로 움직이는 블록을 터치 한 번으로 떨어뜨려
높이 쌓아라! 삐뚤어지면 잘려나간다.


## 게임 방법

- 화면 터치(또는 스페이스바) → 블록 낙하
- 아래 블록과 정확히 겹치면 ✨ 퍼펙트 (너비 유지)
- 어긋나면 삐져나온 만큼 잘려나감
- 완전히 빗나가면 게임 오버
- 높이 올라갈수록 빨라짐 · 최고 기록 저장

## 기술

- Canvas 2D + requestAnimationFrame
- 파티클(잘려나간 조각), 그라디언트 블록, 별 배경
- 최고 기록 localStorage 저장
- 모바일 터치 대응
